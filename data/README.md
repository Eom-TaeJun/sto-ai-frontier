# 입력과 범위

자산·문서 예제는 전부 합성 데이터다. 실존 기업의 재무 수치나 특정 상품의 발행·인가 상태를 나타내지 않는다.

| 파일 | 단위와 의미 |
|---|---|
| `policy_snapshot.json` | 금융위 공개 자료를 확인한 기준일·시행 예정일·출처 |
| `synthetic/rwa_samples.json` | 자산별 검토 시나리오 8건, 원화 금액, 같은 기간의 가용 현금흐름과 원리금 지급액 |
| `synthetic/disclosure_samples.json` | 문서 10건, 대조용 값·출처 ID·예상 규칙 코드 |

`gates`는 시나리오 조건이다. `true`와 `SYN-` 근거가 함께 있어야 시나리오상 확인됨으로 처리한다. `false`는 보류, `null`·누락·근거 없는 `true`는 확인 요청이다. 실제 법률 실사 완료를 뜻하지 않는다.

채무성 자산의 coverage ratio = 같은 기간의 가용 현금흐름 / 원리금 지급액. 재판매·수익배분·MMF에는 적용하지 않는다. 입력 기간·산식 검증과 실제 자료 추출은 미구현이다.

1.2배 검토선, 20% 현금흐름 감소, 자료 연령 90일은 동작 확인을 위한 임의 가정이다. 규제 수치나 교보의 심사 기준이 아니다. 민감도는 `screen_asset(..., stress_haircut=..., max_age_days=...)`로 바꿀 수 있다.

문서 검사 대상은 명시적 `발행규모`, `DSCR` 표기와 제한된 표현 패턴이다. 두 숫자가 함께 나온다는 이유로 불일치를 판정하지 않는다. 원문 중복 필드·복잡한 부정·인용·표·이미지·문맥 전반은 검증하지 못한다. 출력이 없더라도 사람의 검토가 필요하다.
